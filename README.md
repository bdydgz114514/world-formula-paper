## 作者设定

- **枫丹科学院非常规现象研究室研究员**（提瓦特侧）：提供全部物证、史料与方程推导。第一卷以他为主笔。
- **天外偷渡客**（地球侧）：提供提瓦特之外的概念与理论——石油化工、高分子、果胶、熵、博弈论、哥德尔不完备定理、量子场论与重正化群。第二卷以他提供的材料为主。

**这个分工不是装饰，而是结构的一部分**：「提瓦特没有石油」这类观察，本地研究员根本提不出来。凡涉及地球侧术语之处，正文均以「**偷渡客按**」标注；第三卷由两人合写。

## 闸门（check-flow.mjs）

1. **台账锚点**：30 条主张在合订本里逐条找得到落点（带卷号匹配，「第二卷 第五章」只在第二卷里找）；
2. **术语覆盖率**：某词在讲稿出现 3 次而论文 0 次 → 硬失败（单向流动被破坏）；
3. **出戏词零容忍**：游戏内 / 玩家 / 官方 / 策划 / 实装；
4. **插图引用存在性**；
5. **讲稿页码连续性与交叉引用越界**；
6. **简繁混用**；7. **引文保真**（讲稿长引号是否出自论文，未复核的报警告）；8. **表格完整性**（列数一致 + 有表头分隔行）；9. **统计数字一致性**（总数 + **分卷量**，都以《主张台账》现算为准）。

## 讲稿与课件为什么是 164 对 164

第一版讲稿 450 页、课件 164 页，是两次独立作业，页号对不上：翻到「讲稿第 100 页」和「课件第 100 页」是两件事（一个是「元层的能与不能」，一个是「四条路线，一个形状」）。

现在的做法是**让讲稿去适配课件**：

1. 用论文当共同的尺子——把 450 个讲稿页、164 个课件页各自定位回论文里的位置（12 字窗滑窗匹配 + 章节锚点）；
2. 章节级对齐后，把 450 页切成 164 个**连续非空块**，每块给一张课件页（分块 DP + 局部精修）；
3. 按目标顺序重排，正文一字不改，只做三件事：合并页、把原页标题降为页内 `####` 小标题、把正文里的「第 N 页」按新页号重编。

顺带修掉了重排之后会失真的自指（「下面二十二页」→「下面五页」、「这一部一百二十页」→「四十四页」等 10 处）。

复查时又抓到两处：一处是残留的字面 `**`（渲染时漏出星号），一处是「我在第 100 页那张表里已经写开了」——合并后这句话落在了它自己那一页上，改写为「这一页前面那张表」。

第三轮复查（两轮独立审读 + 一个只核对事实的审读员）又修掉：三处内容归属错位（第 11–15、17–27、96–97 页）、一处跨页承接句失效、以及四处**与论文/台账不一致的数字**：同一句话在第 71 页与第 73 页被标成相反的方向与等级（乙级·预测 vs 丙级·回溯）、「二十一条／九条」（真值 22／8）、第一卷等级列 甲10/乙10 与推翻条件 18（真值 甲9/乙10、19）；论文侧同步修了同一张 6.7 表、两处「见 5.3」指针、一处术语（本真→本征）与六处引号不逐字的引用。闸九因此新增**分卷量核算**。

映射固化在 [_merge/讲稿164-映射.json](_merge/讲稿164-映射.json)，重放脚本是 [_merge/rebuild-lecture-164.mjs](_merge/rebuild-lecture-164.mjs)，旧版 450 页原件留在 [_merge/讲稿-合订本-v1-450页.md](_merge/讲稿-合订本-v1-450页.md)。

重排的完整性由「逐字比对」保证：新旧正文去掉标题与页号后**逐字相同（129,514 字）**，差异只有 43 处刻意改写与 1 条全局改称：「这一页的一句话」→「这一节的一句话」（合并后同一页里会出现最多 13 次同名收尾句），以及 12 处「上一页／下一页」在合并后已落在同一页内、改写为「上一节／下一节」。

**这些闸门都是被真实的错误逼出来的**——包括一次「表格被正文截断、导致网页版静默少一行」，和一次「拼接式扩写丢掉 7 张插图」。详见 [抗过拟合机制.md](抗过拟合机制.md)。
