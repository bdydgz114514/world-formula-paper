# 世界式：原理、推理与应用

一篇以《原神》「世界式」为题的完整研究论文。

**作者设定为两人**：

- **枫丹科学院非常规现象研究室研究员**（提瓦特侧）：提供全部游戏内物证、史料与方程推导
- **天外偷渡客**（地球侧）：提供提瓦特之外的概念、名称与理论——石油化工、高分子、果胶、熵、博弈论、哥德尔不完备定理

这个设定不是装饰，而是论文结构的一部分：**正文中「提瓦特没有石油」这类观察，本地研究员根本提不出来**（在提瓦特，糖果有弹性不需要解释）。凡涉及地球侧术语之处，正文均以「**偷渡客按**」标注。

## 关于「高中知识可解释」

论文正文刻意只用高中范围内的数学工具：数列与递推、函数与算子、迭代与不动点、收敛与发散。

超出高中的两个概念——**差别度 D** 与**形式系统／哥德尔不完备定理**——都在第一章用完整小节展开讲清楚了，不预设读者已知。

第九章额外把世界式与三个**高中/常识层面已学过的理论**（热力学第二定律的熵增、囚徒困境、生物演化的变异-选择）做了对照，帮助建立直觉。

## 关于结论的可信度

论文严格区分三类论断，并在第八章列出完整分级：

- **甲级**：原著文本直证（10 条）
- **乙级**：本论文的强推断（6 条）
- **丙级**：弱推断 / 待证（4 条）

第八章同时给出**三个可能的反例**与**五个尚未解决的问题**，读者可据此自行判断。
