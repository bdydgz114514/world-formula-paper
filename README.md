# 世界式 · 大一统理论

两份以《原神》为素材、但**按真实研究方向写**的内部研究纪要，以及一份把它们讲给人听的讲稿。

| 编号 | 文档 | 一句话 |
|---|---|---|
| **第 47 号** | **世界式：原理、推理与应用** | 提瓦特被封闭之后，差别度只会往下走 |
| **第 48 号** | **大一统理论纲要** | 引力的问题，是它在重正化群的递推里缺了一项 |
| **讲稿·总集** | **世界式·总集 讲稿** | 把上面两份，连同三期讲稿，合成一次讲述 |

**作者设定为两人**：

- **枫丹科学院非常规现象研究室研究员**（提瓦特侧）：提供全部物证、史料与方程推导
- **天外偷渡客**（地球侧）：提供提瓦特之外的概念与理论——石油化工、高分子、果胶、熵、博弈论、哥德尔不完备定理

这个设定不是装饰，而是结构的一部分：**「提瓦特没有石油」这类观察，本地研究员根本提不出来**。凡涉及地球侧术语之处，正文均以「**偷渡客按**」标注。

## 三份材料的关系

　　　**素材（知识库） → 论文 → 讲稿 → PPT　　（禁止反向）**

**讲稿不得引入论文里没有的结论。** 这条规矩由 `check-flow.mjs` 强制：某术语在讲稿出现 3 次而两份论文 0 次，判为**硬失败**。

## 关于「高中知识可解释」

论文正文刻意只用中等教育范围内的数学工具：数列与递推、函数与算子、迭代与不动点、收敛与发散。

超出这个范围的两个概念——**差别度 D** 与**形式系统／哥德尔不完备定理**——都在第一章用完整小节展开讲清楚了，不预设读者已知。

## 关于插图

全部 44 张插图由本项目自行生成（matplotlib 绘制几何图元与文字），**未使用任何外部图源**，不涉及版权问题。

## 关于结论的可信度

论文严格区分三类论断：**甲级**（原文直证）、**乙级**（强推断）、**丙级**（弱推断 / 待证）。

更要紧的是第二个轴：**预测 / 回溯**。

　　　**回溯不构成证据**——任何框架都能容纳任何观察，只要允许它事后长出一个新章节。
　　　**只有预测能被推翻，因而只有预测能提供信息。**

**当前成绩：25 条主张里，预测类 2 条（8%），有推翻条件的 18 条（72%），硬失败 0。**

**这份成绩单不好看，但它是真的。**

## 重新生成

```sh
node check-flow.mjs                                    # 改完必跑
node build-html.mjs                                    # 第 47 号
node build-html.mjs 大一统理论纲要.md                    # 第 48 号
node build-html.mjs 讲稿-总集.md                         # 讲稿网页版
node lecture2/build-docx.mjs 讲稿-总集.md "第 一 ~ 三 期 合 订"   # 讲稿 docx
python figs_unified.py                                 # 重绘第 48 号的 14 张图
for f in figs_batch*.py; do python $f; done            # 重绘第 47 号的 30 张图
```

依赖：Python 3 + matplotlib（中文字体 Microsoft YaHei）、Node.js（docx 生成需要 `lecture2/node_modules/jszip`）。

## 一条维护提醒

**交付物重建之后必须打开数一遍**——段落顺序、表格数、分页符数、正文里有没有残留的标记符号。

这条提醒是有来历的：讲稿 docx 曾经因为正则拆错，**每页的标题位置显示的是整页正文**，而它当时是「推荐阅读」的那一份。详见 [抗过拟合机制.md](抗过拟合机制.md) 第六节。
