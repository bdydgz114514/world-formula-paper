## 作者设定

- **枫丹科学院非常规现象研究室研究员**（提瓦特侧）：提供全部物证、史料与方程推导。第一卷以他为主笔。
- **天外偷渡客**（地球侧）：提供提瓦特之外的概念与理论——石油化工、高分子、果胶、熵、博弈论、哥德尔不完备定理、量子场论与重正化群。第二卷以他提供的材料为主。

**这个分工不是装饰，而是结构的一部分**：「提瓦特没有石油」这类观察，本地研究员根本提不出来。凡涉及地球侧术语之处，正文均以「**偷渡客按**」标注；第三卷由两人合写。

## 合订本的三卷

| 卷 | 内容 | 一句话 |
|---|---|---|
| **第一卷** | 世界式：一个封闭系统的算术 | 从三件物证反推出一台自指递推式，证明它在封闭条件下只有一个吸引子（D = 0） |
| **第二卷** | 大一统：一个缺失的项 | 从两个并排写下的式子出发，提出引力的麻烦可能来自「重正化群是一阶的」（丙级） |
| **第三卷** | 接缝：两份材料互相解释 | 两份材料各缺一个「位置」，而那两个位置长得一样；但**互相解释不是互相证明** |

**合订的理由只有一条**：分开读会丢掉它们之间那件事。详见卷首的「合订说明」。

## 体例：每条结论都有两个坐标

| 轴 | 取值 | 问的是 |
|---|---|---|
| **证据强度** | 甲级 / 乙级 / 丙级 | 原文有多硬 |
| **推理方向** | 预测 / 回溯 | 是在看见证据**之前**推出的，还是**之后**套上去的 |

**回溯类结论必须回答「什么情况下它会被推翻」。** 全部 30 条主张登记在《主张台账》里，并在附录 F 印成一张全表。

## 闸门（check-flow.mjs）

1. **台账锚点**：30 条主张在合订本里逐条找得到落点（带卷号匹配，「第二卷 第五章」只在第二卷里找）；
2. **术语覆盖率**：某词在讲稿出现 3 次而论文 0 次 → 硬失败（单向流动被破坏）；
3. **出戏词零容忍**：游戏内 / 玩家 / 官方 / 策划 / 实装；
4. **插图引用存在性**；
5. **讲稿页码连续性与交叉引用越界**；
6. **简繁混用**；7. **引文保真**（讲稿长引号是否出自论文，未复核的报警告）；8. **表格完整性**（列数一致 + 有表头分隔行）。

**这些闸门都是被真实的错误逼出来的**——包括一次「表格被正文截断、导致网页版静默少一行」，和一次「拼接式扩写丢掉 7 张插图」。详见 [抗过拟合机制.md](抗过拟合机制.md)。
