## 这是一份什么样的文档

它不是设定集，也不是剧情复述。它假装成**一份在世界内部写成的研究报告**：一位枫丹科学院的研究员，在整理水仙十字结社遗留物证的过程中，试图把创始人雷内当年那份「世界式」还原出来。

**作者设成两个人，这不是装饰，而是结构的一部分：**

| | 枫丹科学院研究员 | 天外偷渡客（来自地球） |
|---|---|---|
| 提供什么 | 提瓦特侧的全部材料与推导 | 提瓦特之外的概念、名称与理论 |
| 长处 | 知道这里的每一份文本在哪 | **知道「这里缺了什么」** |
| 短处 | **看不见自己世界的盲区** | 对提瓦特一无所知 |

正文中凡涉及地球侧的术语（熵、博弈论、哥德尔不完备定理、石油化工、果胶），均标注为「**偷渡客按**」。

**为什么必须有两个作者**：补论二的核心观察是「提瓦特没有石油」——可本地研究员根本问不出这句话。在提瓦特，糖果有弹性不需要解释。**只有从外面来的人，才会觉得这里缺了一样东西。**

## 核心结论

**世界式是一个在封闭系统中迭代的、以「密合」为算子的自指递推式：**

```
状态：  世界 = 差别度 D 在四象限上的分布（记忆/愿望/灵魂/人格）
算子：  密合 ⊕      表象(3) ⊕ 本征(4) = 密合(7)
递推：  W(n+1) = W(n) ⊕ W(n−1)      初始项一填，整个未来锁定

开放解（法图纳）：⊕ 为生成型 → 2,1,3,4,7,11,18,29…  文明循环
封闭解（世界式）：蛋壳封系统后外源项归零，⊕ 退化为坍缩型
                 D(n+1) ≤ D(n)，唯一吸引子 D* = 0
```

**推导的关键一步**：封闭系统只保证最终进循环或不动点，**不保证**趋向零。真正逼出终末的是——提瓦特仅有的两种底层力（光界力与虚界力）**方向相反，但都是消灭差别的同化力**。所以系统内不存在产生差别的源，唯一吸引子只能是零。

**终末不是「被毁灭」，是「被合并」**——这解释了「连甜甜花和薄荷都长不出来的世界」：**生命就是差别。**

## 四篇补论：从「核实」到「推演」

| | 用的输入 | 结论 | 性质 |
|---|---|---|---|
| 补论一 | 配方、食谱说明、厨房常识 | 火候 = D(t) 的极大值点 | **核实** |
| 补论二 | 配方、染料用途、薄荷精油制法 | 胶基 = 薄荷叶的果胶，不是石油 | **核实** |
| 补论三 | 面积、办事延迟、港口吞吐 | 枫丹廷人口上限约 2 万（1 万~5 万） | **推演** |
| 补论四 | **只有世界式本身** | 下一次大灾难约 73 年后 | **极限推演** |

**补论三**用**李特定律**（在办量 = 到达率 × 停留时间），从一段「办事跑了四趟还没办成」的记录反推出行政系统的吞吐上限，进而算出城市容量。

**补论四**是全文对公式的极限测试：除递推式本身外不引入任何输入。从二阶递推的特征方程解出 φ，推出灾难间隔的收缩比 1/φ²，只需要两个日期作刻度，就给出：

> ## 下一次大灾难：约 73 年后。
> ## 世界的终末：约 427 年后。

**副产品**：公式只用自己的一条比例，独立裁决了「葬火之战发生在 6000 年前还是 3000 年前」这桩年代争议——6000 年说算出的间隔比 0.375 与公式要求的 0.382 吻合到 2%；3000 年说算出的比值是 1.50，方向甚至相反（意味着灾难间隔在变长，而公式要求变短）。

## 一句话概括这套方法

> **一个几乎不需要输入的公式，是一条定律。一个需要很多输入的公式，是一把尺子。**

而那位四百年前的学者手里拿的是定律。**他的错误不在公式，在他拿到公式之后做的事**——他没有去改输入，而是试图**成为**那个不动点。他证明世界会合并，然后他开始合并世界。

## 结论的可信度

论文严格区分三类论断，第八章给出完整分级与**三个可能的反例**：

- **甲级**：原著文本直证（10 条）
- **乙级**：本论文的强推断（6 条）
- **丙级**：弱推断 / 待证（4 条）

其中**补论四的预测是可证伪的**——这是它与全文其他推论的根本区别：`200 年内没有大灾难 → 模型被推翻`。
