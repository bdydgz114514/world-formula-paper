# 页面包（page pack）JSON 格式说明 —— 合订本课件 lecture4-merged

你要产出的**唯一东西**是一个 JSON 文件，形如：

    { "pages": [ {页面1}, {页面2}, ... ] }

写完后请**语法自检**（例如 node -e "JSON.parse(require('fs').readFileSync('...','utf8'))"），
确保是**严格 JSON**：双引号、无注释、无尾随逗号、无 markdown 代码围栏。

## 页面对象

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 页目/备注用标题，≤ 22 字。生成 outline.md 用 |
| `head` | 是 | 页面上那一行大标题，≤ 26 个汉字（含空格标点）。**用 `·` 分隔章号与章名** |
| `sub` | 否 | 大标题下面一行小字，≤ 34 个汉字 |
| `dark` | 否 | true 时深色封面页（仅封面/卷首用） |
| `rows` | 是 | 页面主体，数组，**最多 3 行**（含插图行） |

### row 对象

    { "cols": 2, "cells": [ 单元A, 单元B ] }

- `cols` 只能是 1、2、3，必须等于 cells 的个数。
- 渲染器**自动算高度**：同一行的所有单元等高（取该行最高的那个）。行与行之间自动留 14px。
- **版面纵向预算只有 356px**（y 从 126 到 482），超了自检会报「页脚安全区」。
  参考：一行 3 个「无标题 3 行」卡片 ≈ 88px；一行 2 个「有标题 4 行」卡片 ≈ 136px。
  **安全的组合：两行（如 136 + 12 + 136 = 284）或三行（如 100 + 14 + 100 + 14 + 88 = 316）。**

### 单元 A：卡片

    {
      "k": "card",
      "title": "卡标题",                       // 可省，≤ 16 字（两栏）/ ≤ 11 字（三栏）
      "badge": { "s": "甲级", "c": "gold" },    // 可省；徽标，2~4 字
      "accent": "teal",                        // 可省；配色见下
      "lines": [ "普通一行", { "pre": "方向　", "s": "回溯" }, { "s": "加粗的一行", "w": 700, "f": "navy" } ]
    }

- `lines` 每项可以是字符串，或对象：
  - `s`：文字（必填）
  - `pre`：加粗前缀（与 `s` 同行，用于「标签　内容」）
  - `pf`：前缀颜色（可省，默认取 accent）
  - `w`：700 表示加粗（判断句用）
  - `f`：文字颜色（navy / teal / gold / red / blue / purple / orange / muted）
  - `sz`：字号，默认 13.5；只在需要时写（12 / 12.5 / 13 / 13.5 / 14 / 15）
  - `gap`：在该行之前额外留多少 px（默认 0；用 8 分段）
- **每行字数上限（硬要求，超了自检报「容器高度」）**：
  - 一栏卡（816px 宽）：≤ 44 个汉字
  - 两栏卡（400px 宽）：≤ 24 个汉字
  - 三栏卡（264px 宽）：≤ 15 个汉字
  （数字/西文算半宽；上面按最坏情况给的界。）
- 一个卡片 **最多 6 行**。

### 单元 B：插图

    { "k": "fig", "file": "fig03-coniunctio.png", "caption": "图 3　密合算子。", "maxH": 220 }

- `file` 必须是 `../figures/` 下真实存在的文件名，**一个字都不能改**。
- **不许拉伸**：`w`/`h` 由渲染器按原图比例算，你**不要**写 `w`/`h`。
- `maxH`：限高（px）。竖长图务必写，建议 160~240。
- `caption`：图注，≤ 34 字。**建议逐字照抄论文里的图注**（形如「图 3　密合算子。」）。

### 单元 C：纯文字（少用）

    { "k": "text", "s": "一行说明", "sz": 14, "a": "middle", "f": "muted", "w": 700 }

## 配色代号（accent / c / f 用）

`navy`、`deep`、`teal`、`gold`、`red`、`blue`、`purple`、`orange`、`muted`

**约定**：甲级/回溯 → `gold` 或 `blue`；乙级 → `teal`；丙级 → `orange`；预测 → `red`；推翻条件 → `red`。

## 内容纪律（违反即整页作废）

1. **一字一句都必须来自** `D:\ai\gongzuoqu\tools\world-formula-paper\世界式与大一统-合订本.md`。
   - 允许**截断**原句、允许把原句里的短语拼成一行，但**每一行里必须有 ≥ 10 个连续汉字与原文逐字相同**。
   - **不许**自己造结论、造数字、造引文、造人名地名。
   - 引号 `「」` 内的字必须逐字照抄。
2. **禁用出戏词**（一处都不许出现）：`游戏内`、`玩家`、`官方`、`策划`、`实装`。
3. **每页所有文字（含标题、副标题、卡片、图注）合计 ≤ 200 个字符**（不含空格）。这是硬指标，超了要删。
   参考：一行两栏卡 ≈ 20 字，一行一栏卡 ≈ 40 字。所以一页大概是「2 个卡片 × 4 行」或「1 张图 + 2 个卡片 × 3 行」。
4. **等级与方向必须出现在页面上**：凡是讲判断句的页，卡片上要有 `badge` 写「甲级 / 乙级 / 丙级」或「回溯 / 预测」；
   讲推翻条件的页，`accent` 用 `red` 并让卡标题里出现「推翻」二字。
5. 术语照抄原文：差别度 D、密合、归约、自在/他在、规格、变量位、重正化群、不动点、截断、反项、记忆项……
6. 页面上不要写「本章目标」「本节将讲」「（略）」这类元话语。
